## Overview

A football web app designed for live-score views, standings, top scorers, and tournament grids. The project includes a React and TypeScript frontend, an Express server, and a Vite build setup.

Started in Google AI Studio. This repository is kept separately from the earlier `football` project.

## Run locally

1. Install Node.js and the dependencies:
   ```bash
   npm install
   ```
2. Configure your own `GEMINI_API_KEY` in `.env.local` as required by the app. Never commit private API keys.
3. Start the development server:
   ```bash
   npm run dev
   ```

## Commands

| Command | Purpose |
| :--- | :--- |
| `npm run dev` | Run the TypeScript Express server |
| `npm run build` | Build the frontend and bundle the server |
| `npm start` | Start the built server |
| `npm run lint` | Run the TypeScript check |

## Stack

React · TypeScript · Express · Vite · Tailwind CSS · React Router

## Notes

Live scores and other match data depend on configured services and their availability. The repository is a project workspace, not a guarantee of complete live-data coverage.
